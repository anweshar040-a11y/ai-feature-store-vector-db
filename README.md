# AI Feature Store + Vector Database

A production-style machine learning infrastructure project that builds a feature store and vector database for recommendation systems.

## Project Overview

This project recreates core components of modern ML infrastructure:

* Feature Store for engineered machine learning features.
* Vector Database for similarity search using embeddings.
* Recommendation Engine powered by vector search.
* FastAPI service for serving recommendations.

## Tech Stack

* Python
* SQLite
* Pandas
* NumPy
* FastAPI
* Docker
* PyTest
* Git & GitHub
